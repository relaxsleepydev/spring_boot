# Basics of Web Browser

- **A web browser** is software that retrieves content from web servers and displays it as interactive pages. Examples include Chrome, Firefox, Safari, Edge, and Opera.
- **How it works:** The browser requests a webpage’s files over the network, then uses a rendering engine to turn the code into a visual page. A JavaScript engine runs scripts that enable interactive features.
- **Main components** include the user interface, networking tools, rendering and JavaScript engines, and security features. Common rendering engines include Blink, WebKit, and Gecko.
- **Browser types:** Desktop browsers often offer more features and extensions; mobile browsers are adapted to smaller touchscreens; embedded browsers display web content inside other apps.
- **Common features** include tabs, bookmarks, browsing history, download management, customization, extensions, and syncing across devices.
- **Security:** HTTPS encrypts data sent between a browser and a website, while sandboxing helps isolate websites from the device. Keeping a browser updated helps address security issues.
- **Private or incognito mode** mainly limits what the browser saves locally. It does not necessarily hide activity from websites, employers, schools, or internet providers.
- **A browser is not a search engine:** The browser is the app used to access websites; a search engine is a service used to find information online.
