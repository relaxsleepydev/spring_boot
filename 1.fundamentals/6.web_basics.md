# Basic Terminologies Regarding Web

> **Web page** is a document which can be displayed at a web browser

> **Website** is a collection of web pages grouped together in one resource, with links connecting them together

> **Web server** is a computer that hosts one or more website on the internet. Here hosting means that all the web pages and their associated files are available on that computer

> **Web service** is a software that responds to requests over the internet to perform a function or provide data

> **Search Engine** is a web service that allows you to search other web pages such as Google, DuckDuckGo and are normally accessed through a web browser

# How the Web Works (Basics)
- Your browser requests a website's main page from a web server using HTTP.
- The server sends the page to your browser.
- The browser requests any extra files it needs, such as images, styles, and scripts.
- The browser puts everything together and displays the website.
