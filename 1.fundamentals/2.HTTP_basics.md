# Basics of HTTP

> **HTTP** is the foundation of World Wide Web, and is used to load webpages using hypertext links.

> **HTTP Request** is the way communication platforms such as web browsers asks for information they need to load a website. A typical HTTP request contains:
1. HTTP version type
2. A URL
3. An HTTP method
4. HTTP request header
5. HTTP body (optional)

> **HTTP method** is the action that the HTTP request expects from the queried server.

> **HTTP request header** contains core information which is in text form stored in key-value pair such as the browser used by the client or what data is being requested.

> **HTTP request body** contains the body of information the request is transferring.

> **HTTP response** is the response clients receive from an internet server in answer to an HTTP request. A typical HTTP response contains:
1. An HTTP status code
2. HTTP response headers
3. HTTP body (optional)

> **HTTP status code** is a 3-digit code which is used to indicate the current status of an HTTP request(accepted, rejected, etc) which are broken into following 5 blocks:
1. 1xx = informational
2. 2xx = succes
3. 3xx = redirection
4. 4xx = client error
5. 5xx = server error

> **HTTP response header** conveys important informations such as the language of the data being sent.

> **HTTP response body** contains the information which was requested.
