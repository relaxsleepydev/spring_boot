# Internet:

> In simple words, Internet is a network of networks.

> When you send data over the internet, it is broken up into small packets that are sent from your device to a router which forwards it to next router in the path towards destination until the final destination.

### Basic Terminologies :

> 1. **Packet**: Small unit of data.

> 2. **Router**: Device that directs these packets of data.

> 3. **IP Address**: Identifies a network interface or endpoint, used to route data to the correct destination.

> 4. **Domain Name**: Human readable name to identify website, like google.com.

> 5. **DNS**: Translates domain names into IP addresses (and can provide other DNS records).

> 6. **HTTP**: Used to transfer data between a client (web browser) and a server (website).

> 7. **HTTPS**: Encrypted version of HTTP using SSL/TLS.

> 8. **SSL/TLS**: Used to provide secure communication over the internet.

> 9. **Client & Server**: A client requests information and a server responds to it. 

> 10. **ISP**: Internet Service Provider connects your home or device to the internet.
